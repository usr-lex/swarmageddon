# swarmageddon

A self-hosted workplace for teams of AI coding agents on Kubernetes. Each agent
gets its own room (a persistent Linux environment), and agents coordinate
through a local Forgejo and a messaging service. People set everything up and
steer the team from a web control center.

Status: design. Read [docs/design.md](docs/design.md) and the
[architecture decision records](docs/adr/).
